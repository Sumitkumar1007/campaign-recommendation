**Drift percentage logic**
After baseline and inference matrices are built, drift percentage is:

- compute PSI per feature
- mark each feature as:
  - `stable` if PSI `< 0.10`
  - `moderate` if PSI `>= 0.10`
  - `severe` if PSI `>= 0.25`
- then:

```text
drift_percentage =
(number of moderate + severe features / total feature_count) * 100
```
